# Muonium Player · 独立版 v1.7（不启动 Minecraft）

从 `MuoniumPlayer-1.21.11-fabric-2.2.0.jar` 剥离出的本地音乐播放器：后端纯 Java，前端用系统浏览器打开。不启动 MC，不联网下载额外依赖。

> v1.7 新增「联机一起听」：两台电脑建房/加入，双方共同点歌、暂停、切歌，曲目与状态经免费云端中转同步。

## 版本变体

- **精简 Java 版**：包内自带 jlink 精简 JRE 21，解压即用，体积较小。
- **无 Java 版**：不含运行时，需自行安装 JDK 21 后运行。

## 运行前提

- **Windows · 精简 Java 版**：包内自带 JRE 21（`runtime/` 目录），解压后双击 `run-win.bat` 即可运行，无需另装 Java。
- **Windows · 无 Java 版**：包内不含 `runtime/`，需先自行安装 **JDK 21**（或 JRE 21）；`run-win.bat` 会自动在 PATH、`JAVA_HOME` 及常见安装目录定位 Java。
- **macOS**：包内运行时为 Windows 版，Mac 需自行安装 **JDK 21**（`brew install temurin21` 或官网 dmg）；脚本会自动定位 Java。
- Windows 自带 Edge；macOS 自带 Safari 或安装 Chrome。
- 首次使用为**游客未登录**状态，网易云可搜索、播放试听曲目；VIP/高音质曲目可能受限。

## 启动

### Windows
双击 `run-win.bat`。脚本会在后台起本地后端，并自动用 Edge 以独立窗口打开界面。

### macOS
终端进入本目录：

```sh
chmod +x run-mac.sh
./run-mac.sh
```

后端起后自动用默认浏览器打开 `http://127.0.0.1:18391`。

> 若脚本提示找不到 java，请确认已安装 JDK 21；可在终端执行 `/usr/libexec/java_home -v 21` 查看安装路径。

## 目录结构

```
muonium-standalone/
├─ classes/        编译后的后端类（app.Server 入口）
├─ web/            前端页面 index.html
├─ libs/           运行所需 jar（主 mod + 内嵌库 + Kotlin 运行时 + commons-lang3）
├─ runtime/        自带 JRE 21（Windows，解压即用；Mac 不适用）
├─ src/app/        后端源码备查
├─ run-win.bat     Windows 启动脚本
└─ run-mac.sh      macOS 启动脚本
```

## 当前版本能力

- 网易云关键词搜索，点选播放，上一首/下一首、暂停、进度拖动、音量；**播放模式**可切换顺序 / 单曲循环 / 随机。
- 热搜词展示，点击即搜；**排行榜**内置 65 个网易云榜单，点击即加载曲目。
- 音质档位可选：标准 / 较高 / 极高（未登录时无损、HiRes 不可用，会自动回退到较高档）。
- 背景可在左侧「更换背景图」本地导入：选**一张**为静态背景；选**多张**则在这些图之间随机切换轮播，切换时双层交叉淡化（0.8 秒淡入淡出），间隔由外观区「背景切换」滑块调整（15 秒~3 分钟，默认 1 分钟）。图片保存在后端本地 `data/` 目录，重开界面、换浏览器都保留。
- 播放进度条上方叠加**缓冲/下载进度**条，显示已缓存范围。
- **歌词同步显示**：按时间轴逐行高亮、平滑滚动，含制作人员（作词/作曲等）行与翻译；点击任意一句可跳转到该句时间。
- **收藏歌单**：点歌曲右侧或播放栏的心形即可收藏/取消，收藏列表保存在后端本地 `data/favorites.json`；左侧「查看收藏」打开收藏队列，按顺序连播。
- **播放队列（临时）**：点歌曲右侧的 `+` 或播放栏队列按钮旁的 `+`，把当前曲加入待播队列；播放栏右侧音符按钮弹出/收起队列浮层，可点歌播放、`×` 移出。队列仅存内存，重启软件后清空。
- **专辑封面**：列表行与播放栏显示歌曲封面；封面走后端代理转发并做内存缓存，列表封面按需懒加载、使用缩略图，避免拖慢列表。
- **外观设置**：左侧外观区可调面板透明度、背景模糊、边框描边、玻璃高光、边缘圆角、背景切换间隔滑块，外加 7 色强调色板；选择同时保存到后端本地 `data/config.json`，换浏览器、重启软件都沿用。
- 音频经本地后端代理出流，支持拖动进度（Range）；整曲首次播放后落盘到 `data/cache/`，重复播放直接读本地，缓存上限 300MB 自动清理最旧。
- **联机一起听**：两台不在同一网络的电脑各自运行本程序，一人建房、一人凭房间号+密码加入，双方都能点歌/暂停/切歌/拖进度/切模式/切音质，曲目与播放状态通过免费云端中转实时同步；音频仍各自走本机后端出声，房主无需内网穿透。详见下文「联机一起听」。

## 联机一起听

### 怎么用

1. **房主建房**：点播放栏右侧的双人图标，填昵称、自定义房间号（字母数字 3–24 位）、设置密码，点「创建房间并开启」。
2. **朋友加入**：另一台电脑打开本程序，同样点双人图标，填昵称、同一个房间号和密码，点「加入已有房间」。
3. 加入后双方都能控制：点歌、暂停/继续、上一首/下一首、拖进度、切播放模式、切音质，另一端会自动跟随。
4. 面板里可看到成员列表、一键复制房间号；「同步间隔」滑块在 **1–30 秒**之间可调（默认 3 秒）；点「离开房间」退出。

### 工作方式

- 音频**各自走本机后端**取流出声，房主机器不需要公网 IP，也不用做内网穿透。
- 云端只同步**信令**：当前曲目（id/歌名/歌手/时长/封面）、暂停/播放、进度、播放模式、音质档位，以及成员名单；不传音频文件。
- 状态快照存在免费公共 JSON 中转（MantleDB，免注册）：本地主动操作后整份覆盖写云端；另一端定时轮询拉取，按序号/时间戳判断新旧，非自己刚写的新版本就跟随对齐。

### 联机限制与注意事项

- **房间号要私密、不常见**：未被认领的云端空间，任何人知道房间号都能读写；密码只是弱校验，挡不住懂行者直接读云端，不要在房间里传敏感内容。
- **同步不是逐帧实时**：按设定间隔轮询，进度对齐有 1–2 秒量级误差；间隔调得越短跟得越紧，但云端请求越频繁。
- **免费中转额度**：单空间 100 条记录、单条 64KB、每天约 10000 次请求；间隔过短会更快耗尽。未认领空间 30 天无写入会被清除；该中转属 BETA 服务，稳定性与长期留存不保证。
- **联机状态不跨刷新保留**：刷新页面或重启程序后，需要重新建房或加入。
- 曲目版权仅供本地学习交流使用。

## 已知限制（后续可补）

- 未登录，无法拉取个人歌单/收藏；部分 VIP 曲目无播放链接；无损/HiRes 需登录会员。
- 联机依赖第三方免费中转，若该服务下线或被限流，一起听功能不可用，单机搜索/播放/收藏等不受影响。

## 技术说明

- 后端入口：`app.Server`，本地 HTTP 服务 `127.0.0.1:18391`：
  - `GET /api/search?kw=` 搜索歌曲（JSON）
  - `GET /api/hot` 热搜词
  - `GET /api/charts` 排行榜列表
  - `GET /api/chart?pid=` 某榜单曲目
  - `GET /api/lyric?id=` 歌词（原文 + 翻译 LRC）
  - `GET/POST /api/favorites` 收藏列表（POST 切换收藏，body 含 id/name/artist/duration/source/cover/fav）
  - `GET /api/cover?url=` 封面图代理转发
  - `GET /api/stream?id=&quality=` 音频代理流（quality: STANDARD/HIGHER/EXHIGH）
  - `GET/POST /api/bg` 读取/保存单张背景图（存 `data/` 目录）
  - `GET /api/bgimages` 多图轮播元数据；`GET /api/bgimages?img=N` 取第 N 张；`POST /api/bgimages` 保存轮播图（JSON：interval + images dataURL 数组，存 `data/bgimages/`）
  - `GET/POST /api/config` 读取/保存外观与间隔配置（JSON：alpha/blur/border/glow/radius/accent/interval，存 `data/config.json`）
- 联机信令走外部免费中转 MantleDB：`https://mantledb.sh/v2/<房间号>/state`，`POST` 全量覆盖写、`GET` 读取、`PATCH` 合并、`DELETE` 删除；快照字段：`v/room/password/host/members[{name,at}]/track{id,name,artist,duration,source,cover}|null/paused/pos/mode/quality/seq/updatedAt/by`。后端本身不参与联机，仅提供本机取流/封面/歌词代理。
- 播放链路走纯 JavaSound，不依赖 LWJGL/OpenAL 原生库，便于跨平台。
